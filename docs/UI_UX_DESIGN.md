## 1. 페이지 구조

### 1.1 전체 구조

```
공개 페이지 (로그인 불필요)
├── /                     # 랜딩 페이지
└── /login                # 로그인 (Google OAuth)

인증된 사용자 페이지
├── /dashboard            # 대시보드 (종목 목록 + 추가)
├── /dashboard/stock/:id  # 종목 상세 + 차트
├── /dashboard/history    # 알림 이력
└── /settings             # 계정 설정 (프로필, 테마)

관리자 페이지
├── /admin                # 관리자 대시보드
├── /admin/users          # 사용자 목록
├── /admin/users/:id      # 사용자 상세
└── /admin/logs           # 시스템 로그

개발 환경 전용
└── /showcase             # UI 컴포넌트 쇼케이스
    ├── /showcase/layout
    ├── /showcase/navigation
    ├── /showcase/forms
    ├── /showcase/display
    ├── /showcase/feedback
    └── /showcase/overlay
```

### 1.2 접근 제어

| 페이지 | 조건 | 미충족 시 동작 |
|--------|------|---------------|
| / | 없음 | - |
| /login | 비로그인 | 로그인 상태면 /dashboard 리다이렉트 |
| /dashboard/* | 로그인 필수 | /login 리다이렉트 |
| /settings | 로그인 필수 | /login 리다이렉트 |
| /admin/* | 로그인 + admin 역할 | 403 또는 /dashboard 리다이렉트 |
| /showcase/* | 개발 환경 | 프로덕션에서 404 |

### 1.3 네비게이션 구조

#### 일반 사용자 Header

```
┌─────────────────────────────────────────────────────────────────┐
│  [Logo]     대시보드  |  알림 이력           [프로필] [테마] │
└─────────────────────────────────────────────────────────────────┘
```

| 요소 | 동작 |
|------|------|
| Logo | /dashboard로 이동 |
| 대시보드 | /dashboard로 이동 |
| 알림 이력 | /dashboard/history로 이동 |
| 프로필 | 드롭다운 (설정, 로그아웃) |
| 테마 | 드롭다운 (모드 + 컬러 선택) |

#### 관리자 Sidebar (admin 역할 보유 시)

```
┌──────────────┐
│  [Logo]      │
├──────────────┤
│  대시보드     │  ← 관리자 대시보드
│  사용자 관리  │
│  시스템 로그  │
├──────────────┤
│  내 서비스 →  │  ← /dashboard로 이동
└──────────────┘
```

## 2. 사용자 정보

### 2.1 필드 정의

| 필드 | 타입 | 소스 | 편집 가능 | 기본값 |
|------|------|------|----------|--------|
| email | string | Google OAuth | ❌ | Google 계정 이메일 |
| nickname | string | 사용자 입력 | ✅ | Google 계정 이름 |
| profile_image | string (URL) | Google OAuth | ❌ | Google 프로필 이미지 |

### 2.2 닉네임 규칙

| 규칙 | 값 |
|------|-----|
| 최소 길이 | 2자 |
| 최대 길이 | 20자 |
| 허용 문자 | 한글, 영문, 숫자, 언더스코어(_) |
| 중복 허용 | ✅ (고유할 필요 없음) |

### 2.3 DB 스키마 반영

```
users 테이블 수정:
- name → nickname (명칭 변경)
- 기본값: Google OAuth에서 가져온 name
```

## 3. 테마 시스템

### 3.1 테마 구성 요소

| 요소 | 옵션 | 설명 |
|------|------|------|
| 모드 | Light / Dark / System | 밝기 모드 |
| 컬러 팔레트 | 8개 | Primary 색상 계열 |

### 3.2 컬러 팔레트

| 팔레트 | 설명 | Primary 색상 (Light/Dark) |
|--------|------|---------------------------|
| Zinc | 중립 회색 (기본값) | #18181b |
| Slate | 차가운 회색 | #1e293b |
| Rose | 분홍/장미 | #e11d48 |
| Blue | 파랑 | #2563eb |
| Green | 초록 | #16a34a |
| Orange | 주황 | #ea580c |
| Violet | 보라 | #7c3aed |
| Red | 빨강 | #dc2626 |

### 3.3 저장 방식

| 항목 | 설정 |
|------|------|
| 저장 위치 | 로컬스토리지 |
| 키 (모드) | `theme-mode` |
| 키 (팔레트) | `theme-color` |
| 기본값 (모드) | system |
| 기본값 (팔레트) | zinc |

**선정 이유:**
- 기기별 다른 테마 설정 가능 (노트북 Dark, 모바일 Light)
- 로그인 전에도 테마 적용 가능 (랜딩, 로그인 페이지)
- 구현 단순 (next-themes 기본 동작)
- 테마 설정 유실 시 치명적이지 않음

### 3.4 테마 적용 범위

| 요소 | 테마 영향 |
|------|----------|
| 배경색 | ✅ |
| 텍스트 색상 | ✅ |
| Primary 버튼 | ✅ (팔레트 색상) |
| Secondary 버튼 | ✅ |
| 카드/컨테이너 | ✅ |
| 테두리 | ✅ |
| 차트 색상 | ✅ |
| 아이콘 | ✅ |

## 5. 컴포넌트 Showcase

### 5.1 접근 제어

| 환경 | /showcase 접근 |
|------|---------------|
| development | ✅ 허용 |
| production | ❌ 404 반환 |

**구현 방식:** 환경변수 체크 후 라우트 조건부 등록

### 5.2 페이지 구조

```
/showcase
├── [Header]
│   ├── 로고 + 제목
│   ├── 테마 선택기 (모드 + 컬러)
│   └── 카테고리 네비게이션
│
├── /showcase/layout      # 레이아웃 & 구조 (6개)
├── /showcase/navigation  # 네비게이션 (5개)
├── /showcase/forms       # 데이터 입력 / 폼 (14개)
├── /showcase/display     # 데이터 표시 (6개)
├── /showcase/feedback    # 피드백 & 상태 (6개)
└── /showcase/overlay     # 오버레이 & 팝업 (7개)
```
