# 타이포그래피 스케일 설계

---

## 1. 현재 문제

### 1.1 페이지 헤더 불일치

| 페이지 | 현재 | 태그 |
|--------|------|------|
| 대시보드 "내 알림" | `text-lg font-semibold` (18px) | `<h2>` |
| 알림 이력 | `text-2xl font-bold` (24px) | `<h1>` |
| 설정 | `text-2xl font-bold` (24px) | `<h1>` |
| 관리자 대시보드 | `text-2xl font-bold` (24px) | `<h1>` |
| 사용자 관리 | `text-2xl font-bold` (24px) | `<h1>` |
| 시스템 로그 | `text-2xl font-bold` (24px) | `<h1>` |

대시보드만 `text-lg`(18px)로 다른 페이지보다 작음.

### 1.2 본문 폰트 크기 분포

| 크기 | 사용 횟수 | 비율 |
|------|---------|------|
| `text-xs` (12px) | 14회 | 17% |
| `text-sm` (14px) | 29회 | **55%** |
| `text-base` (16px) | 3회 | 4% |
| `text-lg` 이상 | 13회 | 24% |

**`text-sm`(14px)이 전체의 55%를 차지**하여 프로젝트 전반이 작게 느껴짐. 브라우저 기본 폰트 크기인 `text-base`(16px)는 거의 사용되지 않음.

### 1.3 역할 구분 부족

`text-sm` 하나로 다음을 모두 처리:
- 테이블 데이터 (종목명, 가격, 변동률)
- 필드 라벨 ("기준가", "상승", "닉네임")
- 빈 상태 메시지 ("알림 이력이 없습니다")
- 페이지네이션 텍스트 ("페이지당")
- 임계값 정보 ("상승 +10% (77,000원)")

크기가 같으면 시각적 무게도 같아져서 중요한 데이터와 보조 텍스트의 구분이 어려움.

## 2. 타이포그래피 스케일

### 2.1 계층 정의

| 계층 | Tailwind | px | font-weight | 용도 |
|------|----------|-----|-------------|------|
| **Display** | `text-3xl` | 30px | `font-bold` | Hero 숫자 (현재가 등) |
| **Page Title** | `text-2xl` | 24px | `font-bold` | 페이지 제목 ("설정", "알림 이력" 등) |
| **Section Title** | `text-lg` | 18px | `font-semibold` | 섹션 제목 ("내 프로필", "가격 차트", "알림 이력 (N건)") |
| **Body** | `text-base` | 16px | 기본 | 테이블 데이터, 주요 텍스트, 이메일, 닉네임 |
| **Label** | `text-sm` | 14px | 기본 또는 `font-medium` | 필드 라벨, muted 설명, 보조 텍스트, 페이지네이션 |
| **Caption** | `text-xs` | 12px | 기본 | 종목코드, 폼 에러, 차트 범례, 색상 팔레트 이름 |

### 2.2 핵심 원칙

1. **Page Title은 `text-2xl font-bold`로 통일** — 모든 페이지에서 동일
2. **데이터는 `text-base`(16px)** — 사용자가 읽어야 하는 실제 정보
3. **라벨/보조 텍스트는 `text-sm`(14px)** — 데이터를 설명하는 보조 역할
4. **아주 작은 보조 정보만 `text-xs`(12px)** — 종목코드, 에러 메시지, 범례 등

## 3. 적용 범위

### 3.1 Page Title — `text-2xl font-bold` 통일

**변경 대상:**

| 페이지 | 현재 | 변경 |
|--------|------|------|
| 대시보드 "내 알림" | `text-lg font-semibold` | `text-2xl font-bold` |

나머지 페이지(알림 이력, 설정, 관리자 등)는 이미 `text-2xl font-bold`이므로 변경 불필요.

### 3.2 Body — `text-sm` → `text-base`

**변경 대상 (데이터/주요 텍스트):**

| 위치 | 내용 | 현재 | 변경 |
|------|------|------|------|
| 대시보드 알림 카드 | 종목명, 가격, 변동률 등 데이터 | `text-sm` | `text-base` |
| 알림 이력 테이블 | 종목명, 기준가, 발동가, 날짜 등 | `text-sm` | `text-base` |
| 종목 상세 이력 테이블 | 일시, 기준가, 발동가, 변동률 | `text-sm` | `text-base` |
| 종목 상세 Hero | 임계값 정보 ("상승 +10% (77,000원)") | `text-sm` | `text-base` |
| 관리자 사용자 테이블 | 이메일, 닉네임 등 | `text-sm` | `text-base` |
| 설정 페이지 | 이메일, 닉네임 값 | `text-sm` | `text-base` |

### 3.3 Label — `text-sm` 유지

**변경 없음 (보조 역할이므로 `text-sm` 유지):**

| 위치 | 내용 |
|------|------|
| 종목 상세 Hero | "기준 N원" muted 텍스트 |
| 종목 상세 편집 모드 | "기준가 (원)", "상승 (%)" 라벨 |
| 설정 페이지 | "이미지", "이메일", "닉네임" 라벨 |
| 페이지네이션 | "페이지당 N개" |
| 통계 카드 | "전체 사용자", "전체 알림" 등 카드 제목 |
| 빈 상태 | "알림 이력이 없습니다" 등 placeholder |
| 사이드바 | 유저 정보 영역 |

### 3.4 Caption — `text-xs` 유지

**변경 없음:**

| 위치 | 내용 |
|------|------|
| 대시보드 카드 | 종목코드 |
| 종목 상세 | 종목코드 |
| 알림 이력 테이블 | 종목코드 (괄호 표시) |
| 폼 | 유효성 에러 메시지 |
| 차트 | 범례 텍스트 |
| 테마 | 색상 팔레트 이름 |
| 테이블 헤더 | 컬럼 헤더 (일시, 기준가 등) |

## 4. 변경 전후 비교

### 대시보드 알림 카드

```
[변경 전]
삼성전자          ← text-sm (14px)
005930            ← text-xs (12px)
75,000원          ← text-sm (14px)

[변경 후]
삼성전자          ← text-base (16px)
005930            ← text-xs (12px, 유지)
75,000원          ← text-base (16px)
```

### 알림 이력 테이블

```
[변경 전]
종목명     기준가      발동가      변동률
삼성전자   70,000원   77,000원   +10.00%    ← 전부 text-sm (14px)

[변경 후]
종목명     기준가      발동가      변동률      ← 헤더는 text-xs 유지
삼성전자   70,000원   77,000원   +10.00%    ← text-base (16px)
```

### 종목 상세 Hero

```
[변경 전]
75,000원                              ← text-3xl (유지)
+7.14% (+5,000원)                     ← text-base (유지)
기준 70,000원                          ← text-sm (유지, 라벨)
상승 +10% (77,000원) · 하락 -10% ...   ← text-sm (14px)

[변경 후]
75,000원                              ← text-3xl (유지)
+7.14% (+5,000원)                     ← text-base (유지)
기준 70,000원                          ← text-sm (유지, 라벨)
상승 +10% (77,000원) · 하락 -10% ...   ← text-base (16px)
```

## 5. 주의 사항

- UI 컴포넌트 파일(`src/components/ui/`)은 수정하지 않음 — shadcn/base-ui 기본 스타일 유지
- Showcase 파일은 수정하지 않음
- 사이드바 내부 텍스트는 수정하지 않음 — 사이드바는 좁은 공간이라 현재 크기가 적절
- 테이블 헤더(`<th>`)는 `text-xs` 유지 — 데이터보다 작아야 계층 구분
