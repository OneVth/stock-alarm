# 관리자 대시보드 개선 설계

---

## 1. 현재 상태

**경로:** `/admin`

**현재 구현:**
- 통계 카드 3개 (전체 사용자, 전체 알림, 오늘 발송)
- 네비게이션 버튼 2개 (사용자 관리, 시스템 로그)

**설계 문서 대비 누락:**
- 최근 가입 사용자 테이블
- 최근 알림 발송 테이블

---

## 2. 추가 항목

### 2.1 최근 가입 사용자

관리자가 "최근에 누가 가입했나?" 빠르게 확인하는 용도. 전체 목록은 `/admin/users`에서 확인.

**데이터:** 최근 5명

| 컬럼 | 출처 | 설명 |
|------|------|------|
| 이메일 | User.email | — |
| 닉네임 | User.nickname | — |
| 알림 수 | _count.alerts | 등록한 알림 개수 |
| 가입일 | User.createdAt | 상대 시간 또는 날짜 |

**레이아웃:**

```
최근 가입 사용자
┌──────────────────────────────────────────┐
│ 이메일          닉네임    알림   가입일    │
│ ──────────────────────────────────────── │
│ user1@...      홍길동    5개   3일 전    │
│ user2@...      김철수    2개   1주 전    │
│ ...                                      │
└──────────────────────────────────────────┘
```

하단에 "전체 보기 →" 링크 → `/admin/users`로 이동.

### 2.2 최근 알림 발송

관리자가 "최근에 어떤 알림이 발송되었나?" 확인하는 용도. 이메일 발송 성공/실패 여부 포함.

**데이터:** 최근 5건 (emailSent 여부 무관, 전체 발동 이력)

| 컬럼 | 출처 | 설명 |
|------|------|------|
| 종목명 | Alert.stockName | 관련 종목 |
| 변동률 | AlertLog.changeRate | 색상 강조 (success/destructive) |
| 유형 | AlertLog.thresholdType | Badge (상승/하락) |
| 이메일 | AlertLog.emailSent | Badge (발송/미발송) |
| 일시 | AlertLog.createdAt | 상대 시간 또는 날짜 |

**레이아웃:**

```
최근 알림 발송
┌────────────────────────────────────────────────┐
│ 종목       변동률   유형   이메일   일시         │
│ ────────────────────────────────────────────── │
│ 삼성전자   +10.0%  상승   발송    3시간 전      │
│ SK하이닉스 -6.79%  하락   발송    1일 전        │
│ ...                                            │
└────────────────────────────────────────────────┘
```

하단에 "전체 보기 →" 링크 — 현재 전체 알림 발송 이력 페이지는 사용자 본인의 `/history`만 있으므로, 관리자 전용 전체 이력 페이지가 없다면 링크 없이 표시만.

## 5. 데이터 쿼리

page.tsx에서 기존 통계 쿼리와 함께 병렬 조회:

```ts
const [totalUsers, totalAlerts, todaySentAlerts, recentUsers, recentAlertLogs] = await Promise.all([
  // 기존 3개...
  prisma.user.findMany({
    include: { _count: { select: { alerts: true } } },
    orderBy: { createdAt: "desc" },
    take: 5,
  }),
  prisma.alertLog.findMany({
    include: { alert: { select: { stockName: true, stockCode: true } } },
    orderBy: { createdAt: "desc" },
    take: 5,
  }),
]);
```
