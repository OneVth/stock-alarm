## 1. 디자인 원칙

### 1.1 색상 원칙

| 원칙 | 설명 |
|------|------|
| 4가지 레이어 | 중립 기반 → 기능적 색상 → 시맨틱 → 테마 |
| 60-30-10 대안 | 제품 UI는 90% 중립, 8% 보조, 2% 강조 |
| 뉴트럴 밸런스 | 배경은 배경에 머물러야 함 |
| 다크 모드 | 단순 반전 금지, 색상 간 거리 더 크게 (2% → 4~6%) |
| 기능적 색상 | 파괴적 행위는 빨간색, 성공은 녹색 |

### 1.2 대시보드 원칙

| 원칙 | 설명 |
|------|------|
| 사이드바 | 척추 역할, 그룹화, 아이콘+짧은 제목 |
| 본문 | 한 가지 기능에 집중, 가장 중요한 정보 상단 |
| KPI 반복 피하기 | 불필요한 통계 카드 반복 제거 |
| 4가지 구성 요소 | 목록/테이블, 카드, 사용자 입력, 탭 |
| 상호작용 | 팝오버(간단), 모달(복잡), 새 페이지(영구적) |

### 1.3 일반 UI/UX 원칙

| 원칙 | 설명 |
|------|------|
| 사용자 흐름 | 검색, 건너뛰기, 빈 상태 고려 |
| 효과 최소화 | 그라데이션/그림자 과다 사용 피하기 |
| 간격 | 그리드 정렬, 여백 확보, 자동 레이아웃 |
| 일관성 | 모서리 반경, 버튼 스타일 통일 |
| 아이콘 | 동일 라이브러리 (Lucide), SVG 사용 |
| 중복 제거 | 불필요한 요소 제거 |
| 인터랙티브 피드백 | 호버/클릭 상태, 로딩 표시 |

## 2. 색상 시스템

### 2.1 브랜드 색상

- **Primary**: Blue (Hue ≈ 262)
- **기본 테마**: `data-theme="blue"`

### 2.2 색상 단계 (50~900)

| 색상 | Hue | 용도 |
|------|-----|------|
| Blue | 262 | Primary, 주요 액션, 링크 |
| Success | 150 | 상승, 성공 상태 |
| Warning | 85 | 경고 상태 |
| Destructive | 27 | 하락, 삭제, 위험 |

### 2.3 시맨틱 매핑

| 변수 | 값 |
|------|-----|
| --primary | var(--blue-500) |
| --success | var(--success-500) |
| --warning | var(--warning-500) |
| --destructive | var(--destructive-500) |

### 2.4 사용 예시

```tsx
// Primary 버튼
<Button className="bg-primary">확인</Button>

// 상승 표시
<span className="text-success-500">+5.2%</span>

// 하락 표시
<span className="text-destructive-500">-3.1%</span>

// 경고 배경
<Alert className="bg-warning-100 border-warning-300">
```

## 3. 레이아웃 시스템

### 3.1 사이드바

#### 상태

| 상태 | 너비 | 표시 | 저장 |
|------|------|------|------|
| 펼침 | 240px | 아이콘 + 텍스트 | localStorage |
| 접힘 | 64px | 아이콘만 | localStorage |
| 모바일 | 0px (숨김) | Sheet로 열기 | - |

#### 구조 (펼침)

```
┌────────────────────┐
│                    │
│  Stock Alarm       │
│                    │
│  ────────────────  │
│  📊 대시보드        │  ← 메인 네비게이션
│  🔔 알림 이력       │
│                    │
│  ────────────────  │  ← admin 역할만 표시
│  🛡️ 관리자         │
│                    │
│  ────────────────  │
│  [Avatar] 사용자    │  ← 프로필 영역
│  🎨 테마  ▼        │  ← 팝오버로 열기
│  🚪 로그아웃        │
│                    │
│  ────────────────  │
│  [◀ 접기]          │  ← 토글 버튼
```

### 3.2 필터 탭

#### 용도

통계 카드 4개 → 필터 탭으로 대체

#### 형태

```
내 알림
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐                          │
│  │ 전체 2  │ │ 활성 2  │ │ 비활성 0 │        [+ 새 알림 추가]  │
│  └─────────┘ └─────────┘ └─────────┘                          │
│   ^^^^^^^^                                                     │
│   (선택됨 = 밑줄)                                               │
│                                                                │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │ 테이블                                                    │ │
│  └──────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

#### 탭 동작

| 탭 | 필터 조건 | URL |
|----|----------|-----|
| 전체 | 모든 알림 | /dashboard |
| 활성 | `isActive = true` | /dashboard?filter=active |
| 비활성 | `isActive = false` | /dashboard?filter=inactive |

#### 스타일

- shadcn/ui `Tabs` 컴포넌트 사용
- 선택된 탭: 밑줄 + 굵은 글씨
- 숫자: 뱃지 또는 괄호

#### 컴포넌트

| 컴포넌트 | 경로 | 역할 |
|----------|------|------|
| `alert-filter-tabs.tsx` | components/stock/ | 필터 탭 UI |

## 4. 페이지별 개선 계획

### 4.1 대시보드 (/dashboard)

| 항목 | 현재 | 개선 방향 |
|------|------|----------|
| 통계 카드 | 4개 반복, 정보량 적음 | 2~3개로 간소화 또는 마이크로 차트 추가 |
| 테이블 | 행 구분 약함 | 호버 상태, 줄무늬 또는 구분선 |
| 여백 | 넓게 퍼져있음 | max-width 설정, 그리드 정렬 |
| 버튼 | 검정 (Zinc) | Blue Primary 적용 |
| 빈 상태 | 미확인 | 알림이 없을 때 안내 UI |

### 4.2 종목 상세 (/dashboard/[id])

| 항목 | 현재 | 개선 방향 |
|------|------|----------|
| 정보 카드 | 기본 스타일 | 계층 구분 명확히 |
| 차트 | 기본 스타일 | 그리드, 범위 선택기 개선 |
| 알림 이력 | 테이블 | 행 구분, 호버 상태 |
| 레이아웃 | 세로 나열 | 정보 + 차트 + 이력 그리드 |

### 4.3 알림 이력 (/history)

| 항목 | 현재 | 개선 방향 |
|------|------|----------|
| 테이블 | 기본 스타일 | 대시보드와 스타일 통일 |
| 뱃지 | 상승/하락 | success/destructive 색상 적용 |

### 4.4 관리자 (/admin/*)

| 항목 | 현재 | 개선 방향 |
|------|------|----------|
| 통계 카드 | 기본 스타일 | 마이크로 차트 또는 아이콘 |
| 테이블 | 기본 스타일 | 행 구분, 호버 상태 |
